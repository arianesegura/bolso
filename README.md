# Bolso

App de finanças pessoais (PWA). Os dados ficam no aparelho (localStorage); use Exportar/Importar para backup.

## Publicar no GitHub Pages
1. Envie TODOS os arquivos desta pasta para a raiz do repositório.
2. Settings > Pages > Branch `main` > pasta `/ (root)` > Save.
3. Abra `https://SEU-USUARIO.github.io/bolso/` no celular.

## Instalar
- Android (Chrome): menu ⋮ > Instalar app.
- iPhone (Safari): Compartilhar > Adicionar à Tela de Início.

## Atualizar o app depois
Altere os arquivos, aumente a versão em `sw.js` (const CACHE) e envie de novo.
